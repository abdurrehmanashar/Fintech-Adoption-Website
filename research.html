Research page

How the study was built

A transparent path from research question to data, methodology, modelling, and validation.

Research question

Does formal financial access in Pakistan translate into actual digital financial usage - and can distinct behavioural segments be identified independently of that question?

Most financial inclusion research measures access - account ownership, phone ownership, internet availability - as if it were the same thing as inclusion. This study treats that as an empirical question rather than an assumption, and tests it directly against individual-level survey data.

Dataset

Global Findex 2025, Pakistan

Individual-level microdata from the World Bank's Global Findex Database, the primary demand-side data source for cross-country financial inclusion research.

  • n = 1,000
    respondents, individual-level
  • 183 variables
    demographics, access, behaviour, resilience
  • May-Dec 2024

Methodology

From raw survey data to a validated finding

Four stages, each building on the last, with an explicit correction built into the pipeline early on.

01 - TARGET

Adoption Tier

A four-level ordinal target built from account and digital-usage indicators: Excluded, Basic, Digitally Engaged, Advanced.

02 - LEAKAGE AUDIT

Caught and fixed

An early run that included the variables used to define the target produced spurious near-perfect accuracy. Those seven variables were removed before any reported result.

03 - MODELLING

Supervised + unsupervised

Random Forest and XGBoost for prediction; k-means run independently, blind to the target label, for segmentation.

04 - VALIDATION

Robustness suite

Hyperparameter tuning, repeated cross-validation, calibration analysis, ablation study, and bootstrap cluster stability.

Models

Four classifiers, one used as the analytical instrument

Logistic Regression, Decision Tree, Random Forest, and XGBoost were all trained. Random Forest (tuned) was selected as the model used for explainability and diagnostics, based on macro F1.

A macro F1 around 0.49 given four imbalanced classes and n=1,000 is the realistic ceiling for this feature set - not a shortfall to be tuned away. The model's role in this study is interrogative, not predictive: it exists to extract feature-outcome relationships (via SHAP and permutation importance) and cross-validate the segmentation below, not to serve as a deployable individual-level classifier. Full model comparison numbers and the feature-importance chart are on the Interactive Data page.

Clustering

An independent check, not a re-labelling of the target

k-means was run on demographic, access, behaviour, and resilience variables only - the Adoption Tier target was never a clustering input, at any stage.

This separation is deliberate. Because Adoption Tier is itself constructed from account and digital-usage indicators, including it as a clustering feature would let the clusters trivially reproduce the target rather than reveal independent structure. k was selected via silhouette score (k=2 to 5, k=3 selected), and the resulting cluster labels - like "Connected but Unengaged" - are descriptive summaries applied after clustering, not categories the algorithm was told to find. The full cluster explorer is on the Interactive Data page; the headline finding is on Findings.

SHAP

Explaining the model, not just scoring it

The tuned Random Forest was explained using SHAP TreeExplainer values, averaged across all four Adoption Tier classes, with dependence plots for the top-ranked features.

A useful distinction throughout this study: SHAP, Gini, and permutation rankings describe a variable's contribution to model output, not a cause of adoption. Findex is a cross-sectional survey, so no causal identification strategy is used here - a feature ranked highly is one the model relies on to predict, which is informative about association, not proof that changing it would change behaviour. Full SHAP ranking and dependence plots are on the Interactive Data page.

Robustness

Every major finding was stress-tested

Rather than reporting a single train-test split, model performance and the cluster structure were both checked for stability using independent methods.

MODEL

Repeated cross-validation

50 folds (5-fold x 10 repeats) of the tuned Random Forest: mean macro F1 = 0.480, 95% CI [0.447, 0.521] - tightly bracketing the single-split estimate of 0.494.

CLUSTERS

Bootstrap stability

100 bootstrap resamples of the k=3 solution: Adjusted Rand Index = 0.904 (95% CI [0.847, 0.982]) - the cluster structure is highly reproducible.

FAIRNESS

The accuracy paradox

Raw subgroup accuracy looks higher for women (85.2% vs. 68.9% for men) - but this is a class-imbalance artifact, not fairer treatment. See below.

Because gender is very strongly associated with cluster membership and outcome in this population (Cramer's V = 0.807), the majority of women fall into the large, easy-to-predict Excluded class - which mechanically inflates aggregate accuracy for that subgroup without reflecting anything about fairness. We recommend subgroup-level macro F1, not aggregate accuracy, for fairness audits in similar settings. A second check found the model's predicted probabilities are poorly calibrated for the Excluded class - it assigns roughly 40% probability when the true observed rate is closer to 65-70%, meaning raw probabilities would understate the scale of exclusion if used for resource targeting without recalibration.

Limitations

What this study cannot tell us

The strongest claims are often the ones that clearly define their boundaries.

Association is not causation

The analysis identifies relationships but does not prove intervention effects - Findex is cross-sectional, with no causal identification strategy applied.

Unweighted sample

All reported proportions describe the n=1,000 sample as collected, without Findex's survey design weights - they are not adjusted population estimates.

Small subgroups

The Basic tier (n=21) is too small for reliable per-class evaluation by any model tested - a sample-size constraint, not a modelling failure.

Self-reported data

Several measures rely on reported behaviour and inherit standard survey-based limitations.

What comes next

Questions the next study should answer

  • Longitudinal data: how do people move between segments over time?
  • Qualitative research: why are connected people not engaging?
  • Causal methods: which interventions actually change behaviour?
  • Cross-country replication: is the access-usage gap universal?
  • Reweighted reanalysis: do the proportions hold under Findex's survey weights?
  • Intervention testing: what closes the gap in practice?
